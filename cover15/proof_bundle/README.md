# 十五个全等圆盘覆盖单位圆盘：完整验证包

数学正文：`PROOF_zh.md`。精确数值由 `core/system15.py` 的148元整数二次系统以及 `core/root15.json` 的唯一隔离根定义；不是由一个浮点最优值定义。

## 完整重放

在本目录运行：

```sh
python3 -S -B verify_all.py
```

依赖：Python 3.10+、C++17 编译器（g++ 或 clang++）、Boost.Multiprecision 头文件。接受端不需要任何 Python 第三方包、数值优化器或网络。不支持 `-O` / `-OO` / `PYTHONOPTIMIZE`，程序会主动拒绝关闭断言的环境。

第一次运行会在 `replay_workspace/` 确定性生成五族共11,950,884个轨道代表，再独立逐代表检查有效性、去重、完整群作用的稳定子质量以及与标号计数递推的一致性。较大的未压缩中间文件没有重复放入压缩包；重放需要预留数GB磁盘和内存。已有代表文件可缓存，但每次都会重新审计并检查其哈希与度量证书一致。

```sh
# 强制从生成器重新产生全部代表，之后仍执行所有独立接受检查
python3 -S -B verify_all.py --regenerate

# 限制同时运行的枚举/审计进程数
python3 -S -B verify_all.py --jobs 2
```

程序重新编译 C++ 工具，执行两个根盒、覆盖上界、76维锚点隔离、五族轨道质量、完整度量分区、候选及全部43,013个非候选连续角域，最后执行篡改拒绝测试。

成功时最后输出：

```text
R15 COMPLETE CERTIFICATE CHAIN VERIFIED
11907870 + 43013 + 1 = 11950884; unresolved leaves = 0
```

主报告写入 `reports/MASTER_VERIFIED.json`，汇总日志为 `reports/FULL_REPLAY.log`，各阶段另有日志。任意异常、未访问节点、缺失类型、非法索引或不等式失败都会非零退出并删除主成功报告。存档成功标志从不替代实际重放。

## 文件分工

`core/` 包含标准库接受器、代数根、定量正定证书和候选角域树。`enumeration/` 包含三个 C++ 源码、完整度量分类和残余列表、唯一候选图映射，以及五个逐条流式读取的非候选森林压缩文件。`reports/` 是本次实际重放输出；`SHA256SUMS_PROOF_INPUTS.txt` 绑定参与该次重放的证明源码与原始证书。

`discovery/` 保留不被接受端信任的研究脚本，使用 NumPy、SciPy（发现时为1.17.0）和 mpmath。它不是另一套接受器。运行这些探索脚本时，应建立独立工作目录，复制 `core/`、`enumeration/` 的文件及 `discovery/` 中相关脚本与输入；不要在已验证包内直接覆盖证书。生成器的 `.bin` 文件和按族的分区数据是后续发现脚本的中间输入。完整重放不需要运行这些数值脚本，也不需要重新搜索力证书。
