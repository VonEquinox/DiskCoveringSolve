## 重放

```sh
python3 -S -B verify_all.py
```

需要 Python 3.10+、C++17 编译器（g++ 或 clang++）、Boost.Multiprecision 头文件及小端机器。验证不需要网络，不需要安装数值优化软件。已在 Linux 小端环境测试。重放会在 `_runtime/` 生成约 395 MiB 的面表和编译程序；这些是临时数据，不必预先下载。主程序使用两个并行的枚举/审计任务。

成功时产生 `reports/MASTER_VERIFIED.json` 并打印 `R15 COMPLETE CERTIFICATE CHAIN VERIFIED`。不得关闭 Python 断言。开始或失败时旧主成功报告会被删除。

## 文件结构

`core/` 包含根定义、精确区间运算、覆盖验证、锚点隔离、候选树和全部分支树重放器。

`enumeration/` 包含枚举生成器、采用不同遍历规范化的独立审计器、精确 Farkas 数据、全体残余面表、候选图映射和流式非候选森林。临时的 11,950,884 个面集代表由源代码重建；接受仍需独立验证有效性、无重复性和完整轨道质量。

`reports/` 保存本次实际重放的报告和日志。旧报告不是接受依据；主程序重新计算。

`discovery/` 为可选的数值发现脚本，不在接受链内。它们使用数值优化提出候选或力证书，提出的结果仍须由 `core/` 精确检查。

关键分区：11,907,870 个度量排除 + 43,013 个非候选排除 + 1 个候选全域证明 = 11,950,884 个完整轨道。候选树 2,029 节点；非候选森林 58,905 节点；未决叶为零。

这是一份带正文几何归约的计算机辅助证明，不是 Lean/Coq 形式化，也不声称已经经过独立同行评审。
