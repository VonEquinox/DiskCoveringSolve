## 首次重放

```sh
python3 -S -B verify_all.py
```

需要 Python 3.10+、C++17 编译器（g++ 或 clang++）、Boost.Multiprecision 头文件及小端机器。接受过程不需要网络、NumPy、SciPy、mpmath 或优化器。Python 断言必须启用。

默认命令重新生成全部 53,059,205 个组合轨道的临时面表，再采用不同的广度优先规范化逐项独立验证有效性、去重、稳定子和完整轨道质量。`_runtime/` 中的面表约需 1.9 GiB；计算需要数 GiB 内存。可用 `--jobs 1` 降低并发内存，默认并发两族。

已生成面表时可运行：

```sh
python3 -S -B verify_all.py --reuse-enumeration --jobs 3
```

复用模式仅跳过再次生成；面表仍是不可信输入，所有数学接受检查与默认模式相同。随附正式报告来自本轮新生成面表后的这种独立整链重放，生成日志另存于 `reports/GENERATION_*.log`。首次解压未附面表，不能直接使用复用选项。

成功时产生 `reports/MASTER_VERIFIED.json`，并打印 `R16 COMPLETE CERTIFICATE CHAIN VERIFIED`。开始及失败时删除旧主成功报告；旧报告的成功字段不是接受依据。

## 文件结构

- `core/`：根系统、精确区间、覆盖验证、局部矩阵、候选树、整数杆力与逐树重放。
- `enumeration/`：枚举器、不同规范化的独立审计器、四杆/六杆 Farkas 数据、176 条残余面表、候选映射及175个非候选的森林。
- `reports/`：实际生成及重放日志、每步结果、主报告。
- `discovery/`：可选发现程序；不属于证明接受链。其工作区准备方法见该目录 README。

完整分区：53,059,029 个度量排除 + 175 个非候选排除 + 1 个候选全域证明 = 53,059,205 个轨道。

候选树：10,347 节点，其中5,173个分支、5,052个力叶和122个局部叶。
非候选森林：713节点，其中269个分支、444个力叶。未决叶为零。
