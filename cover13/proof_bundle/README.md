# r13：完整的计算机辅助证明与精确证书

本文证明的是：用十三个等半径闭圆盘覆盖单位闭圆盘的最优半径等于所附 119 元二次系统定义的代数数 r*，约为

`0.34664545692738964346786973819387878953718745296678...`。

首先阅读 **PROOF_zh.md**。它包含任意覆盖到完整枚举的几何归约、独立计数递推、所有局部/全局不等式及证明闭合，而不仅是运行日志。

## 重放

```sh
python3 -B verify_all.py
```

需要 Python 3.10+、C++17 编译器（g++ 或 clang++）和 Boost.Multiprecision 头文件。运行不用网络、不用第三方 Python 包。Linux/WSL 等具备这些工具链的环境可以直接执行。不得使用 `-O`、`-OO` 或关闭断言；检查器会主动拒绝。

最终结果位于 `reports/MASTER_VERIFIED.json`；每个阶段另有日志。主程序会重新执行每一个验证器并重新编译轨道审计器，不能靠空证书目录或旧 `verified:true` 报告通过。`work/` 中的数据和可执行文件是运行时生成，可删除。

## 内容

- `core/`：代数根、上界覆盖、锚点局部隔离、候选全域分支、跨阶段接口、度量筛选及非候选分支的精确验证器。
- `enumeration/`：308198 个轨道代表（压缩文本）、全群稳定子/轨道质量审计源码、度量分区和1760个非候选树的整数证书。
- `reports/`：本次实际重放的报告和日志，仅供核查；重放不把这些预存输出当作证明输入。
- `MANIFEST_SHA256.json`：源代码和证书的文件校验和，不替代数学验证。

所有最终接受判断使用整数或有理数。数值求解器只用于发现构型、矩阵合同变换和边力；验证包不需要重新执行发现过程。

证明不依赖此前 r11、r12 的下界结论。不把“局部最优”“抽样未发现反例”“优化器返回成功”混同于全局证明。

这份成果是一份已在本次环境完整重放的计算机辅助证明，不是 Lean/Coq 形式化证明，也尚未经过独立的第三方同行审查。理论归约的详细证明和可审计的信任边界见正文。
